# 自定义 API 与本地模型

进入「用户菜单 → AI 服务」。配置分为在线 API、本地文字模型、语音转写。保存后的文字模型用于全部文字 AI 功能：笔记解释和续写、出题、复习评阅、思维导图、编程题分析、课堂纪要。无需各模块重复设置；失败不自动切换到云端。

## 在线 API

手动填写 OpenAI 兼容地址、模型和密钥，或导入 JSON 文件后确认保存。示例：

```json
{"baseUrl":"https://api.deepseek.com/v1","model":"deepseek-chat"}
```

文件可包含 `apiKey`，但这意味着源文件存有明文密钥，请妥善保管，不要提交到 Git。导入只填写表单，点击保存后密钥才以系统加密形式保存。切换至本地时保留加密的在线配置，切回在线不会丢失密钥。

## 本地文字模型

先安装并启动 Ollama，再检测现有模型。选择模型、生成自检，再保存 AI 设置。本地地址默认为 `http://127.0.0.1:11434/v1`，也允许其他本机 OpenAI 兼容服务（如 LM Studio）。无需填写在线密钥。本地模式不允许远程地址或云模型。

本机 i5-12500H、16GB 内存、RTX 3050 Laptop 4GB 显存，现有 `qwen3.5:4b` 已通过中文生成和 JSON 自检。它的权重及上下文可能需要 CPU/显卡混合运行；`qwen2.5:1.5b` 更轻，但复杂代码和结构化输出能力较弱。向量模型如 bge-m3 不用于文字生成。

硬件自检显示 CPU、内存、显卡、显存与参考磁盘空间，给出估算推荐。推荐不等于准确率保证；点击生成自检会用合成提示词测试实际中文输出和 JSON 格式，不发送个人笔记。原始请求也会检查 Ollama 模型是否为本地文字生成模型。

可安装推荐模型或输入自定义 Ollama 模型名称。下载前显示大小估计并要求确认，下载进度可取消。单文件 GGUF 可通过文件选择器导入，由本机 Ollama 创建独立模型；不覆盖现有模型。仅支持 Ollama 支持的模型架构，不直接执行模型中的 Python 代码。首次下载需要网络，之后推理在本机完成。

小模型可以接入所有入口，但长项目、深层思维导图或复杂出题仍可能因为上下文、JSON 格式或模型能力不足失败。应缩小输入范围并核对结果。本地生成超时上限为五分钟，模型加载也计入耗时。

## 本地语音转写

推荐 SenseVoice INT8，由 CPU 执行。现有课堂转写继续使用该模型，与文字模型独立。语音页可安装运行环境和模型、导入含 `model.int8.onnx`、`tokens.txt` 的 SenseVoice INT8 目录，并运行实际模型加载和解码自检。

语音自检使用本机静音样本并强制执行解码，验证运行链路，不代表老师口音或编程术语的识别准确率。转写模型不是 GGUF 文字模型，二者不能互换。录音期间不能变更语音模型。

运行环境需 Python 3.11；未安装时按提示安装。模型和运行环境不随学习资料备份导出，也不随应用安装包附送。所有安装和导入只影响本机，功能从 1.0.0 起提供。
