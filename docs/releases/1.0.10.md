# 码迹 1.0.10

- 优化课堂结合项目的 AI 总结：增大代码处理批次，减少重复上下文，并分别保存各文件的分析结果。
- 课堂总结增加任务进度、取消和继续入口；中断后可复用已完成的 AI 返回结果。
- 语音模型设置显示安装目录、占用空间和磁盘剩余空间，支持选择磁盘并迁移模型及运行环境。
- 语音安装增加阶段进度和中断后继续入口，已有下载可复用；取消安装会停止后台安装进程。
- 应用更新失败时显示具体阶段和错误代码，提供官方发布页下载入口。

迁移模型会校验复制结果，并保留原目录。确认新位置运行正常后，可手动清理原目录。磁盘预留估计包含运行环境和下载缓存，实际占用会随依赖变化。

课堂总结缓存保存在本机，删除对应课堂时一并清理；缓存不包含在学习数据备份中。
