# 码迹 1.0.8

- 悬浮知识点窗口新增暂停／继续转录按钮，与主窗口共用同一套课堂操作。
- 语音转写新增可选 Qwen3-ASR-0.6B，支持下载、选择 CPU 或 NVIDIA GPU，并在本地解码验证通过后切换。
- 新增短录音测试，可用 1～30 秒 WAV／FLAC 检查识别结果、推理用时和显存占用。
- Qwen 使用独立 Python 环境。请先安装 Python 3.11，下载后在「AI 服务 → 语音转写」点击「验证并使用此模型」。

Qwen 运行资源和识别效果需要在本机验证，本次未完成 RTX 3050 4GB 的真实模型测试。建议先使用短录音测试，再用于整节课。

Windows x64 用户可在应用中检查更新，或下载 `maji-setup-1.0.8-x64.exe` 覆盖安装。
