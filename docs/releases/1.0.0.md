# 码迹 1.0.0

从课堂记录到知识整理，本次大版本加入课堂纪要与本地 AI，同时保留笔记、晨考、思维导图、复习和编程题分析。

## 课堂纪要

- 新增独立入口，支持电脑系统声音、麦克风和录音文件导入。
- SenseVoice INT8 在本机 CPU 转写，音频不上传，默认不保存原始录音。
- 开启自动 AI 纪要后，每两分钟整理 80～150 字、最多五条关键知识点，结束课堂时处理尾段；生成速度取决于转写与所选模型。
- 原文每两分钟独立分组：标题保留课堂总时间，组内从 00:00 重新计时，默认展开最新组，旧组可折叠回看。
- 支持失败重试、原文查看、Markdown 导出及课堂记录持久保存。

## 在线与本地 AI

- 设置拆分为在线 API、本地文字模型、语音转写三部分，支持导入 API JSON 配置后确认保存。
- 检测 CPU、内存与显卡，提供本地模型参考推荐；支持 Ollama 模型列表、下载进度及取消、GGUF 导入、中文与 JSON 生成自检。
- 全部文字 AI 功能共用所选在线或本地配置，本地失败不自动回退云端；切换服务保留加密的在线密钥。
- 语音模型支持安装、导入 SenseVoice INT8 模型目录和实际解码自检，录音期间禁止切换模型。

## 升级与数据

- 课堂转写与纪要纳入学习备份，数据库结构升级为 8，可恢复结构 6、7 的旧备份。
- 升级前请导出备份。旧应用不能打开升级后的数据库；恢复旧备份会整体替换资料，并清空旧备份未包含的课堂记录。
- 模型、Python 环境、API 密钥和原始录音不在学习备份内。安装包不附带模型；语音转写需要 Python 3.11 和本地运行环境，Ollama 文字模型需要另行安装或下载。
- 硬件推荐仅供参考，自检验证运行链路；编程术语转写、AI 解释及代码仍需人工核对。

Windows x64 用户可通过「应用更新」升级，或下载 `maji-setup-1.0.0-x64.exe` 覆盖安装。
