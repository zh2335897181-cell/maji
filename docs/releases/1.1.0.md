# 码迹 1.1.0

- 新增桌面 AI 助手：在「用户菜单 → 桌面 AI 助手」启用，支持透明悬浮、拖动、大小调整、置顶、昵称和回复性格设置。
- 内置 CC0 授权的「小码 · 太空机器人」，启用即可使用，无需建模软件、Live2D Core 或额外模型下载。
- 助手聊天复用「AI 服务」配置，支持多轮对话、取消回复、失败重试和清空历史；不自动读取笔记、项目或桌面，不执行系统操作。
- 新增四步自定义导入：选择文件 → 检查与隔离预览 → 填写授权 → 确认保存，可选择立即启用。
- 2D 支持 PNG/GIF/WebP 图片、动图和声明式分层角色包；3D 支持 VRM 0.x / 1.0 与资源内嵌的 GLB。表情、眼动和动作能力取决于格式与实际绑定，不自动转换或补全骨骼。
- 导入保存作者、来源、许可原文、署名、改动说明和资源摘要。明确禁止商业使用、分享改编或再分发的声明会阻止导入；授权记录是用户声明，不等于平台认证或新授予的权利。
- 新增角色来源与授权查看、更新记录、移除本地副本。取消或失败不切换当前角色；旧副本缺少授权记录时可补充或直接移除。

自定义角色合计最多128MB，最多20个；不支持外部网络资源、脚本包、Live2D、Spine、FBX或OBJ直接导入。完整格式、授权要求与边界见项目文档 `docs/assistant-model-import.md`。

助手默认关闭，在设置中启用后随码迹启动；隐藏后可从设置重新显示，退出码迹时关闭。对话仅在本次运行中保留。自定义模型和授权记录保存在本机，不自动上传、分享或加入应用安装包。

Windows x64 用户可在应用中检查更新，或下载 `maji-setup-1.1.0-x64.exe` 覆盖安装。
