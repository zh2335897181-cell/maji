# 码迹 1.0.1

- 课堂支持「暂停转录／继续转录」，继续同一条记录；暂停期间不采集新音频、不计入两分钟分段，暂停时也可结束保存。
- 统一为每两分钟一张知识点卡片，展开查看对应原文，原文时间从零显示；移除底部重复的原文分组。
- 开启 AI 纪要的课堂在全部转写和分段纪要完成后，自动汇总全部原文，生成 Markdown 并保存到「课程与笔记 → 课堂总结」。支持复制、打开笔记及失败重试，重复操作不会重复创建笔记。
- 支持编辑课堂标题、分段知识点及转写原文，保留原始时间；检测编辑冲突，手动清空知识点不会误显示为生成中。
- 删除课堂前需确认，只删除该课堂的转写和纪要，已生成的总结笔记保留。编辑课堂也不会覆盖原总结笔记，页面会提示其可能过时。
- 主窗口最小化后显示置顶知识点悬浮窗，可拖动标题栏移动、拉伸边缘缩放；新一段纪要完成后替换旧内容，恢复主窗口时隐藏。隐藏小窗不停止转录。

自动整堂课总结仅在该课堂开启 AI 时运行。长课堂分批整理后合并，结果仍需结合原文核对。模型运行环境沿用已有设置，无需重新安装；升级前建议导出备份。

Windows x64 用户可在应用内检查更新，或下载 `maji-setup-1.0.1-x64.exe` 覆盖安装。
