# 码迹 1.0.4

- 整堂课总结使用官方 DeepSeek Flash / V4 Pro 接口时，将单次请求输出额度提高到最高 384K（393,216）token。实际可输出数量仍取决于模型上下文和服务限制。
- 移除最终总结原有 6000 字符约束；应用接收和课堂记录保存上限调整为 160 万字符，响应大小上限提高到 16 MiB，等待时间延长为 30 分钟。
- 每两分钟的简短知识点纪要保持不变，其他模型和第三方兼容接口保留原有请求额度，避免发送不支持的参数。
- 本次暂不添加分段续写；若服务仍返回输出截断，继续提示重试，避免将不完整内容作为完整总结保存。

Windows x64 用户可在应用中检查更新，或下载 `maji-setup-1.0.4-x64.exe` 覆盖安装。已有失败的课堂总结可在升级后重新生成。
