# 码迹 1.0.3

- 修复课堂总结笔记直接显示 Markdown 符号的问题。新笔记按标题、加粗、嵌套列表、表格和真实代码块排版，支持继续编辑。
- 在课堂纪要页面新增「修复旧笔记格式」：将旧版自动生成的纯文本 Markdown 笔记转换为排版格式，不调用 AI。只转换仍保留原始生成内容的旧模板，手动改写过的正文会受到保护。
- 保留课堂页「复制 Markdown」功能，笔记工具栏仍可复制和导出 Markdown。
- 修复 Markdown 导出遗漏嵌套列表内容、合并列表内独立段落及丢失表格结构的问题。
- 改进解析后的文档校验兼容：内联代码使用独立格式，空引用、空列表项及以代码块开头的列表项保持编辑器和备份格式有效。原始 HTML 仅按文字保留，不执行。

更新后，新生成的总结直接获得排版。已有总结请进入对应课堂，点击「修复旧笔记格式」；若提示笔记已编辑，可保留原笔记，避免覆盖个人修改。

Windows x64 用户可通过应用内检查更新升级，或下载 `maji-setup-1.0.3-x64.exe` 覆盖安装。升级前建议导出备份。
