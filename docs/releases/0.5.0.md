# 码迹 0.5.0

本次更新新增 AI 思维导图，并包含此前已推送的上下文 AI 续写。

- 从单篇或多篇笔记生成导图，选择详细程度、组织方式、代码示例与易错点。
- 生成前确认来源，节点显示引用及来源更新/删除状态。
- 编辑节点、解释与代码，移动或删除分支，撤销重做、搜索、缩放和折叠。
- AI 扩展、精简与重新生成支持结果预览，防止覆盖请求期间的修改。
- 导图自动保存到本机，支持未保存草稿恢复与关闭重开后的恢复。
- 导出 PNG、Markdown、JSON，导入 JSON 备份。
- 根据选中分支生成复习题，沿用答题评阅和复习记录。
- 适配小窗口面板，并提供画布快捷键帮助。

使用入口：左侧「思维导图」，或笔记「更多 → AI 生成思维导图」。AI 功能沿用设置里的 OpenAI 兼容服务，密钥保存在本机；只有确认生成后才发送所选内容。已有导图可离线编辑。

安装包将升级本机数据库结构，请保留原有应用数据；卸载时不要删除笔记数据。Windows x64 安装包及自动更新文件随本版本发布。
