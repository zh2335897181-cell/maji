# 码迹 0.6.0

新增「考试与错题」模块：

- 按考试和日期整理题目，分别保留题干、老师答案、原始答案和订正。
- 多文件项目代码支持 Controller、Service、Mapper、实体、前端与配置层；选择参与 AI 分析的文件。
- AI 分析解题步骤、代码引用和缺失信息；结合错题分析弱项，单题证据标记为疑似。
- 按知识点生成基础理解、定点修复、多层综合训练，提交后查看答案与 AI 评阅。
- 保存有效作答时长、训练层次和反馈；掌握状态支持建议和手动调整。
- 自动保存、关闭前保存及草稿保护；考试、代码、分析和训练资料纳入本地备份恢复。

数据库升级到结构 7，兼容结构 6 的旧备份。恢复旧备份会整体替换资料，并清空旧备份中不存在的考试记录；恢复前会生成安全备份。升级前建议先导出备份，不要删除原有数据库。

AI 复用现有模型设置与用户密钥，发送前确认范围。不执行项目代码；图片题需补充文字，本版不提供 OCR。

验证：264 项单元测试；1440×900、1280×800 下录题、多文件、AI 分析、训练及答案隐藏流程；隔离桌面 SQLite 的写入、版本冲突、备份恢复检查。AI 测试使用模拟响应，实际出题与评阅结果需核实。
