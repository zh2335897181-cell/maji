# 码迹 · 界面与组件设计规范

> 面向编程初学者的本地学习笔记桌面应用。本文是界面设计的唯一说明文档，
> 与 `src/styles/tokens.css`、`src/components/**` 一一对应，可直接作为前端实现规格。
>
> 配套设计稿见 `design/` 目录（24 张，1440×900 与 1280×800 实机截图）。

---

## 1. 设计目标与取舍

| 目标 | 设计上的做法 |
| --- | --- |
| 快速记录，不打断学习节奏 | 打开即编辑；停止输入 0.7 秒自动保存；保存状态常驻顶栏，不需要用户确认 |
| 按课程、主题、语言整理 | 左侧固定课程目录（可折叠为图标栏）＋标签＋语言过滤，不做多层嵌套文件夹 |
| 代码、输出、解释容易区分 | 四种语义区块：普通正文 / 代码块 / 运行结果 / 提示与报错，各自有独立底色、图标与左边框 |
| 笔记与练习、复习相连 | 右侧辅助栏固定展示「复习状态」与「关联练习题」，复习页每条知识点都能回到原笔记 |
| 快速找到旧笔记 | 顶栏搜索入口（Ctrl+K）＋独立搜索页，标题/正文/代码/标签统一检索，命中字段直接标出 |
| 知道是否已保存、避免误删 | 顶栏四态保存指示；删除一律二次确认并列出将被删除的内容 |

**刻意不做的事**：不做仪表盘式统计图表、不做学习时长排行榜、不使用大面积渐变与玻璃拟态、
不给每个区域套厚重卡片。界面的信息密度向「可以连续用两小时」看齐，而不是向「首屏好看」看齐。

## 2. 颜色

主强调色是一种克制的青蓝（teal-blue），只出现在：当前选中项、主要按钮、链接、键盘焦点。
红 / 黄 / 绿只用于错误、提醒、成功，且统一降低饱和度。

| --- | --- | --- |
| `--accent-50` | `#eef6f8` | 选中项底色、柔和按钮 |
| `--accent-100` | `#d9ebf0` | 文本选区 |
| `--accent-200` | `#b6d8e2` | 柔和块描边 |

| `--accent-600` | `#1f6a80` | **主按钮、链接、选中文字（白底对比度 6.1:1）** |
| `--accent-700` | `#18566a` | 主按钮悬停 |
| `--accent-800` | `#123f4e` | 主按钮按下 |

### 2.3 语义色

| 语义 | 文字 | 底色 | 描边 | 使用位置 |
| --- | --- | --- | --- | --- |
| 成功 | `--success-600` `#2c7452` | `--success-bg` `#edf6f1` | `--success-border` `#cde5d8` | 已保存、已掌握、创建成功 |
| 提醒 | `--warning-600` `#94641a` | `--warning-bg` `#fbf4e7` | `--warning-border` `#ebdcb8` | 待复习、逾期、容易混淆 |
| 错误 | `--danger-600` `#b0453d` | `--danger-bg` `#fbefee` | `--danger-border` `#f0d3d0` | 保存失败、删除、常见报错 |

### 2.4 课程配色（低饱和，仅用于课程标识）

7 种可选：`teal` `blue` `violet` `amber` `green` `rose` `slate`，每种提供
`--course-{key}-fg / -bg / -border` 三个令牌。**颜色只用于区分，不承载状态含义**，
且始终与课程名同时出现，不单独用颜色传达信息。

### 2.5 笔记正文语义区块

| 区块 | 底色 | 描边 / 左边框 | 图标 | 说明 |
| --- | --- | --- | --- | --- |
| 普通解释 | 无 | 无 | — | 15px / 行高 1.8，阅读主色 `--ink-800` |
| 代码块 | `--code-bg` `#f7f9fa` | `--code-border` | 语言名 + 复制按钮 | Shiki 高亮，头部 32px |
| 运行结果 | `--output-bg` `#f2f7f4` | `--output-border` 绿 | `Terminal` | 与代码块同构，绿色系区分「这是输出」 |
| 容易混淆 / 说明 | `--tip-bg` `#fbf6ea` | `--tip-border` 琥珀 | `Lightbulb` | 3px 左边框强调 |
| 常见报错 | `--danger-bg` `#fbefee` | `--danger-border` 红 | `TriangleAlert` | 同上 |

深色主题（`html[data-theme="dark"]`）提供同名令牌的另一套取值，组件无需改动。

## 3. 字体与排版

```
--font-sans: "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", "Microsoft YaHei",
             "Source Han Sans SC", "Noto Sans SC", system-ui, -apple-system, "Segoe UI", sans-serif
--font-mono: "JetBrains Mono", "Cascadia Mono", "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace
```

| 令牌 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--font-size-3xl` | 24px / 1.35 | 600 | 笔记标题（编辑页 H1） |
| `--font-size-2xl` | 20px / 1.35 | 600 | 页面标题 |
| `--font-size-xl` | 17px / 1.5 | 600 | 小节标题（正文 H2） |
| `--font-size-lg` | 15px / 1.8 | 400 | **笔记正文（用户可调 14–17px）** |
| `--font-size-md` | 14px / 1.6 | 400 | 界面正文 |
| `--font-size-sm` | 13px / 1.55 | 400–500 | 列表项、按钮、表单 |
| `--font-size-xs` | 12px / 1.5 | 400 | 时间戳、辅助信息、标签 |

- 代码统一 `--font-mono` 12.5px / 行高 1.72，`tab-size: 4`。
- 正文字号最小 12px，界面里不出现小于 12px 的文字（图标内文字除外）。
- 正文最大宽度 `--editor-max-width: 720px` 并居中，**不横向铺满窗口**。

## 4. 间距、圆角、阴影、尺寸

**间距**：4px 基准，`--space-1` … `--space-16`（4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64）。
组件内边距只用 `--space-2` / `--space-3` / `--space-4`；区块间距用 `--space-5` / `--space-6` / `--space-8`。

**圆角**：`xs 3` / `sm 4` / `md 6` / `lg 8` / `xl 12` / `full 999`。
按钮与输入框 `md`，面板与代码块 `lg`，弹窗 `xl`，标签 `sm`。
不使用 `16px` 以上的圆角卡片。

**阴影**（只用于浮层，静态区域不用阴影）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-xs` | `0 1px 2px rgba(19,26,32,.06)` | 分段控件选中态 |
| `--shadow-sm` | `0 1px 3px …` | 轻微抬起 |
| `--shadow-md` | `0 8px 24px …` | 下拉菜单、轻提示 |
| `--shadow-lg` | `0 24px 48px -12px …` | 模态框、抽屉 |

**结构尺寸**：顶栏 48px，侧栏 240px（折叠 56px），右侧辅助栏 250px，编辑工具栏 40px，
控件高度 28 / 32 / 36px，图标 12 / 14 / 16px。

**焦点**：`outline: 2px solid var(--accent-400)`，`outline-offset: 2px`，任何可聚焦元素都可见。

## 5. 布局规范

### 5.1 全局骨架

```
┌──────────┬───────────────────────────────────────────────┐
│ 产品标志 │ 顶栏 48px   [搜索入口 Ctrl+K]  [保存状态][用户]│
│ 首页/课程├───────────────────────────────────────────────┤
│ 复习/搜索│                                               │
│          │                页面内容                       │
│ 课程目录 │                                               │
│ (可折叠) │                                               │
│          │                                               │
│ [+新建]  │                                               │
└──────────┴───────────────────────────────────────────────┘
```

### 5.2 笔记编辑页三栏

| 区域 | 宽度 | 内容 |
| --- | --- | --- |
| 左：全局导航 | 240px | 产品标志、首页、课程与笔记、复习、搜索、课程目录（可展开）、新建内容 |
| 中：编辑画布 | 自适应 | 面包屑 → 标题（可编辑）→ 收藏/导出/更多 → 工具栏 → 正文（最大 720px 居中） |
| 右：辅助栏 | 250px | 笔记大纲、标签、复习状态、关联练习、笔记信息 |

**分隔方式**：细边界线 + 留白。中栏白底，左右两栏 `--bg-subtle` 浅灰底 + 1px 分隔线。
不使用「卡片里再放卡片」。

### 5.3 折叠顺序（响应式）

| 窗口宽度 | 行为 |
| --- | --- |
| ≥ 1360px | 三栏全展开 |
| 1200–1359px | **先收右侧辅助栏**，顶栏出现「大纲」按钮，点击以浮层形式展开（250px，`--shadow-lg`） |
| 1000–1199px | 左侧导航折叠为 56px 图标栏（课程变成色块，悬停显示课程名） |
| < 1000px | 左侧导航变为抽屉，顶栏出现展开按钮；正文宽度保持 ≥ 600px |

编辑区在任何宽度下都不得被挤到无法阅读；`--editor-max-width` 只限制最大宽度，不设最小宽度。

### 5.4 其他页面

- **学习首页**：两栏 `1fr + 340px`（< 1180px 变单栏）。左栏「继续学习 + 近期学习记录」，右栏「今天的复习 + 快速新建」。
- **课程与笔记管理**：`232px` 浏览栏 + 表格。表格列：笔记 / 课程 / 语言 / 更新时间 / 复习状态 / 操作。
- **搜索页**：居中单栏，最大 1080px。搜索框 32px 高、18px 字号，下方筛选行，结果行含命中字段徽标。
- **复习页**：单栏卡片队列，最大 1080px，每张卡片只放「知识点标题 + 一句摘要 + 三个动作」。
- **新建内容**：顶部 4 个类型选择块（可换）+ 620px 表单 + 创建成功状态。

## 6. 组件规范

所有组件都在 `src/components/ui/`，样式在 `controls.module.css` / `display.module.css` / `overlay.module.css`。

### 6.1 按钮 `Button`

| 变体 | 用途 | 默认 | 悬停 | 按下 | 禁用 |
| --- | --- | --- | --- | --- | --- |
| `primary` | 每屏最多一个主要动作 | `--accent-600` 白字 | `--accent-700` | `--accent-800` | 40% 透明 + 禁用光标 |
| `secondary` | 与主按钮并列的常规动作 | 白底 + `--line-strong` 描边 | `--bg-hover` + `--ink-300` 描边 | `--bg-active` | 同上 |
| `ghost` | 工具栏、列表行内的低干扰动作 | 透明 + `--ink-600` | `--bg-hover` | `--bg-active` | 同上 |
| `soft` | 需要一点颜色但不抢主按钮 | `--accent-soft` + `--accent-700` | `--accent-soft-hover` | — | 同上 |
| `danger` | 不可逆操作（删除确认里的确认键） | `--danger-600` 白字 | `#993b34` | `#85332d` | 同上 |
| `dangerGhost` | 危险操作的次要入口 | 透明 + 红字 + 红描边 | `--danger-bg` | — | 同上 |
| `selected` | 筛选/切换按钮的选中态 | `--accent-soft` + 青蓝字 + 描边 | — | — | — |

尺寸：`sm 28px` / `md 32px`（默认）/ `lg 36px`；可带左右图标；`loading` 时替换为 13–16px 转圈并禁用。

### 6.2 图标按钮 `IconButton`

28 / 32px 方形，必须有 `label`（渲染为 `aria-label` + `title`）。
状态：默认 `--ink-500` → 悬停 `--bg-hover` + `--ink-800` → 按下 `--bg-active` →
选中 `--accent-soft` + `--accent-700` → 危险悬停 `--danger-bg`；禁用 40% 透明。

### 6.3 输入控件

| 组件 | 规格 |
| --- | --- |
| `TextField` | 高 32px，`--radius-md`，默认描边 `--line-strong`；悬停 `--ink-300`；聚焦 `--accent-400` + `0 0 0 3px --accent-soft`；错误 `--danger-500` + 红色文字说明 |
| `TextareaField` | 同上，最小高 88px，可纵向拉伸 |
| `SelectField` | 高 32px，自绘箭头，右侧留 32px |
| `Checkbox` | 16px，选中药 `--accent` 填充 + 白色对勾 |
| `Switch` | 34×20px，轨道 `--line-strong` → `--accent`，滑块 180ms 位移 |
| `SegmentedControl` | 容器 `--bg-sunken` + 2px 内边距；选中段白底 + `--shadow-xs` + 青蓝字 |

**字段结构固定为**：标签（可选「必填」星号 + 说明）→ 控件 → 错误文字 或 示例文字。
错误与示例互斥，避免一屏两行提示。

### 6.4 标签 `Tag`

高 22px，`--radius-sm`，字号 12px。语气：`neutral`（默认）/ `accent` / `success` / `warning` /
`danger` / `subtle`（无描边，用于 `#标签`）/ `mono`（语言名，等宽字体）。
可点击时是 `<button>`，带悬停底色；带 `onRemove` 时显示 11px 关闭图标（支持 Enter / Space）。

### 6.5 列表行

- **导航项**：高 32px，图标 16px + 文字 + 可选计数徽标；选中态青蓝底 + 青蓝字 + 500 字重。
- **课程目录项**：高 30px，展开箭头 18px + 课程色块 + 名称 + 笔记数。
- **笔记行（侧栏）**：高 28px，13px 文字，左侧 1px 竖线形成层级；收藏显示星标，有待复习显示状态点。
- **笔记行（管理页）**：六列网格，行高 48px，悬停出现「…」操作菜单；标题 `--ink-800` 500 字重 + 摘要 12px。

### 6.6 浮层

| 组件 | 规格 |
| --- | --- |
| `Modal` | 遮罩 `rgba(19,26,32,.42)`；面板最大 440px（宽版 640px），`--radius-xl` + `--shadow-lg`；头部含 32px 图标块 + 标题 + 说明；底部按钮区浅灰底 + 上分隔线；Esc / 点遮罩关闭；打开时焦点移入，Tab 在内部循环，关闭后焦点还原 |
| `ConfirmDialog` | 基于 `Modal`，默认危险语气，标题为问句（「删除这篇笔记？」），说明后果，`details` 槽列出将被删除的对象 |
| `Menu` | 面板 200px 起，`--radius-lg` + `--shadow-md`；菜单项高 32px；支持图标 / 勾选 / 快捷键提示 / 危险项 / 分隔线；上下方向键移动、Esc 关闭并还原焦点 |
| `Toast` | 底部居中，深色胶囊（`--ink-800`），白字 14px，`--shadow-md`；3.2 秒自动消失（带操作时 6 秒）；语气用左侧图标颜色区分；最多同时 3 条 |
| `SearchOverlay` | 遮罩 + 居中面板，最大 640px；输入行 48px 高、17px 字号；筛选行浅灰底；结果最多 8 条，`↑↓` 选择、`Enter` 打开、`Esc` 关闭；底部提示快捷键与「查看全部结果」 |

### 6.7 状态指示

| 组件 | 规格 |
| --- | --- |
| `SaveStatus` | 顶栏右侧 26px 高胶囊。`有未保存的修改`（黄点）/ `正在保存…`（灰色转圈）/ `已保存`（绿色对勾，悬停显示时间）/ `保存失败，点击重试`（红色，可点击） |
| `StatusDot` | 6px 圆点：待复习黄、即将到期青、已掌握绿、未排期灰 |
| `EmptyState` | 居中：44px 圆角图标块 + 14px 标题 + 12px 说明（最长 380px）+ 动作按钮组；紧凑版用于侧栏与卡片内 |
| `骨架屏` | 浅灰渐变扫光，1.4 秒循环；编辑页用「标题条 + 三行正文条」，列表页用 6 行 |

### 6.8 代码块

```
┌───────────────────────────────────────────────┐
│ python ▾        Python 代码            ⧉ 复制 │  ← 头部 32px，浅灰底
├───────────────────────────────────────────────┤
│ def greet(name):                              │  ← 12.5px 等宽，Shiki 高亮
│     return f"你好，{name}！"                   │
└───────────────────────────────────────────────┘
```

- 语言可切换（8 种：Python / JavaScript / TypeScript / HTML / CSS / Java / C / 纯文本）。
- 复制按钮点击后图标变对勾、文字变「已复制」，1.8 秒后恢复。
- 光标进入代码块时切换为可编辑纯文本（避免高亮层与光标打架），整块被选中时光标自动落入代码内。

### 6.9 语义块

统一结构：左边框 3px + 头部（图标 15px + 12px 标签）+ 内容区（14px / 行高 1.6）。
编辑态悬停时头部右侧出现类型切换下拉（说明 / 容易混淆 / 常见报错 / 运行结果）。

## 8. 无障碍与交互细节

- 所有可点击元素都是原生 `button` / `a` / `input`，Tab 可到达，`:focus-visible` 有 2px 青色焦点环。
- 图标按钮一律提供 `aria-label`（例如「复制代码」「展开笔记大纲」），用户菜单为「小林（用户菜单）」。
- 弹层 `role="dialog" aria-modal="true"`，打开时焦点进入、Tab 循环、Esc 关闭、关闭后焦点还原。
- 搜索浮层 `role="dialog"`，`↑↓` 选择、`Enter` 打开、`Esc` 关闭；空结果给出可执行的两个出路。
- 轻提示区域 `role="status" aria-live="polite"`，不打断输入焦点。
- 状态从不只靠颜色表达：复习状态既有颜色点也有文字（「待复习 / 已掌握 / 已逾期 2 天」）。
- 快捷键：`Ctrl/Cmd+K` 搜索、`Ctrl/Cmd+N` 新建笔记、`Ctrl/Cmd+S` 立即保存、
  `Ctrl/Cmd+P` 切换编辑/预览、`Ctrl/Cmd+B` 折叠侧栏、`Esc` 关闭浮层。

## 9. 图标规范

全部来自 Lucide React，线性风格，线宽 2，`currentColor` 取色：

| 尺寸 | 场景 |
| --- | --- |
| 16px | 侧栏导航、工具栏按钮、图标按钮 |
| 14px | 菜单项、列表内操作、次要按钮 |
| 12–13px | 标签、状态徽标、行内提示 |

不混用表情符号、彩色图标或第二套图标库。课程图标只能从 `src/lib/icons.ts` 的
12 个白名单中选择，避免出现风格不统一的图标。
