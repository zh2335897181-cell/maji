# 课堂纪要

独立入口。默认每两分钟整理一次新增转写，输出 80～150 字、最多五条关键知识点；跳过闲聊与重复内容。原文及纪要按课堂保存，结束时处理不足两分钟的尾段。

每两分钟一张卡片，标题保留课堂总时间（如 02:00–04:00），卡片内展示纪要及可展开的「查看本段原文」，原文时间从 00:00 重新显示。不再重复显示底部原文分组；未满两分钟或未开启 AI 时也保留对应原文卡片。分组仅改变展示，保留完整原文及原始时间，不覆盖历史内容。跨越边界的原始转写块归入其开始时间所在组，避免重复显示或截断文字。

本机采用 SenseVoice INT8（sherpa-onnx CPU）转写，支持 Windows 默认系统声音、麦克风和录音导入。模型与 Python 运行环境位于 userData/speech-runtime，不加入 Git 或安装包；提供安装脚本。开始前显示设备和隐私说明，只有主动开启 AI 纪要才发送文字到已配置服务。音频不上传、不执行音频中的指令。默认不持久化原始录音。

本模块从 1.0.0 起提供。运行环境与模型需要单独安装，可在「AI 服务 → 语音转写」中安装和自检。

转写按约 20 秒分块，属于分段转写，不承诺逐字实时字幕。摘要在跨过 120 秒边界后触发，无人声时不调用 AI；请求排队且失败保留原文。CPU 忙碌时结果可能延迟。关闭应用会停止录音，已保存分段保留。更换输出设备后需停止再开始。

录制或导入过程中可点击「暂停转录」，点击「继续转录」后继续同一次课堂。实时录制暂停期间丢弃新音频，不计入原文时间和两分钟纪要分段；导入暂停时停止读取后续文件内容。已进入转写或摘要队列的内容会继续处理。暂停状态也可直接结束课堂，保留已采集的尾段。

开启 AI 纪要的课堂在正常结束全部转写、分段纪要后，会从全部原文整理整堂课知识点，自动保存到「课程与笔记 → 课堂总结」课程。长课堂分批整理后合并，不直接截断原文。笔记中的 Markdown 代码框可一键复制，课堂页也提供「复制 Markdown」「打开总结笔记」。失败时保留原文并支持重试；重复操作不会覆盖已创建笔记或重复新建。关闭 AI 或没有可识别原文时不自动生成。已有课堂可点击「生成整堂课总结笔记」。

课堂结束并处理完成后，可编辑标题、各段知识点和原文，分段时间不变。编辑时检测记录版本，避免覆盖更新后的内容。已生成的总结笔记保留，不自动覆盖；课堂页会提示总结可能已过时。删除需确认，仅删除课堂原文与纪要，独立总结笔记保留。

开启 AI 的课堂运行期间，最小化主窗口会在屏幕右上角显示置顶悬浮窗。拖动标题栏移动，拖动窗口边缘调整大小；只展示最新一段成功生成的知识点，下一段完成后替换旧内容。恢复主窗口时隐藏，也可单独隐藏悬浮窗；隐藏不停止录制。录制结束后已显示的小窗保留最后一段，直至隐藏或恢复主窗口。

在「用户菜单 → 外观与编辑 → 悬浮窗透明度」用滑块调整整个悬浮窗的不透明度，范围 10%～100%，默认 100%。拖动即时生效并保存到本机，重启后继续使用；不影响主窗口透明度。

## 安装与使用

需要 Python 3.11、独立虚拟环境、sherpa-onnx 1.13.8 和 SenseVoice INT8 模型。安装 Python 3.11 后，可通过设置页安装，或从项目目录运行：

```powershell
python speech/install.py --runtime "$env:APPDATA\码迹\speech-runtime"
```

进入左侧「课堂纪要」→ 开始课堂 → 选择电脑声音或麦克风 → 确认是否启用 AI。老师在腾讯会议讲话时选择「电脑声音」，无需打开自己的麦克风。结束后等待尾段处理完毕再关闭。音频导入支持 WAV、FLAC、OGG、MP3（实际支持取决于解码库，失败会显示原因）。

课堂转写和摘要纳入学习备份。数据库结构升级为 8，可恢复结构 6、7 的旧备份；旧应用不能打开升级后的数据库。模型、Python 环境和原始音频不在备份中。首次安装前保留独立 SQLite 安全副本。

## 验证

`node scripts/native-classroom-check.cjs` 使用临时用户目录，验证真实中文音频转写、120 秒摘要和 10 秒尾段（本机模拟 AI，未调用付费模型）、系统声音录制与停止、SQLite 持久化以及备份恢复，不读取个人笔记库。识别术语与老师口音的效果仍需真实课堂实测。
