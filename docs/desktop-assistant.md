# 2D / 3D 桌面 AI 助手

从右上角「用户菜单 → 桌面 AI 助手」启用。启用后跟随码迹启动，退出码迹时关闭；窗口右上角的 × 只隐藏助手，可在设置中再次显示。无模型时也可以展开聊天。

## 形象配置

已内置 CC0 许可的 Cosmic Bot（界面名「小码 · 太空机器人」），启用后直接显示，不需要 VRoid Studio、Live2D Core 或 VR 设备。角色随安装包提供，运行时不会联网下载。素材来源、SHA-256 和许可见 `public/assistant/MODEL-LICENSE.md`。

可在「当前角色」切换形象，调整昵称、性格、大小、置顶与鼠标跟随。通过「导入 2D / 3D 角色」按四步完成选择、预览、授权与确认，支持 PNG/GIF/WebP、声明式分层2D包、VRM和内嵌GLB。完整步骤、条例和边界见 [自定义角色导入说明](assistant-model-import.md)。

自定义模型和授权记录复制到 userData/assistant/models。移除副本不影响原文件，并自动切回内置机器人。内置角色不能误删。没有授权记录的旧副本也可直接删除；需补充真实授权后才能选用。

待机呼吸、眨眼、跟随目光、挥手和点头能力因格式及绑定而异；图片不自动变成骨骼模型，通用GLB只播放已有动画。自定义角色的授权独立于渲染库许可，完整记录不等于平台认证。

## 使用

- 拖动名字左侧的把手移动窗口，位置会保留；更换显示器后自动限制在可见工作区。
- 点击角色或「和我聊聊」打开对话，Enter 发送、Shift+Enter 换行。可取消回复或清空对话，发送失败时保留输入供重试。
- 复用「AI 服务」中的全局配置，不需要单独填写密钥。未配置时会提示原因，不会自动改用其他服务。
- 仅发送对话；不自动读取笔记、项目、桌面，也不执行系统操作。最近最多 20 条、总计 20000 字保存在本次进程内，退出即清除，单次输入最多 4000 字。
- 角色运行在无 Node、无 preload、不能访问应用桥接接口的独立来源 iframe 中，禁止连接外网。渲染最高 30 FPS，隐藏窗口时由 Chromium 的后台节流限制运行。
- 出现加载错误时，可重新加载角色，或在设置中切回内置机器人。

## 开发验证

`npm test` 验证资源导入和对话状态；`npx playwright test e2e/assistant.spec.ts` 验证设置与聊天界面。先运行 `npm run build`，再执行 `node scripts/test-assistant-electron.cjs`，在隔离临时目录检查真实透明窗口、聊天桥接、来源隔离、错误恢复和关闭重建。

原生测试会实际加载随包提供的 CC0 机器人，检查透明窗口、模型加载、动作菜单、聊天、隔离与关闭重建。其他 VRM 角色仍需分别验证兼容性；AI 网络调用使用测试替身。
