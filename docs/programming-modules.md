# 编程题分析模块

当前源码将「编程题分析」作为默认入口：一道编程题一个模块，名称自行填写。

1. 点击「新增模块」，填写题目名称。
2. 在笔记式编辑器中整理题目要求，可补充参考答案和自己的解题思路。
3. 按模块导入项目代码。默认自动识别 Controller、Service、Mapper 等分类，也可以指定导入分类、调整单个文件或创建自己的分类。
4. 点击「分析当前模块」，确认发送范围后获取解题步骤、答案、涉及的知识点及代码引用。

分类只属于当前题目。重命名分类会同步本题文件；移除自定义分类时，文件内容保留并归入「其他」。不同题目允许使用相同文件名。

每次 AI 分析只发送当前题目的要求、参考答案、解题思路和勾选的文件。未勾选文件只发送文件目录，不发送代码。解析保存在当前题目中，修改题目后会提醒重新分析。

内容支持自动保存和手动保存，并随现有本地备份一起保存。原有考试、错题和训练数据可通过「查看历史考试与训练」访问。

此调整从 0.6.1 起提供。
