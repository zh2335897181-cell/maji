# 晨考内容整理

晨考是独立的誊写与保存模块。左侧「晨考」入口按日期倒序展示记录，同一天可以保存多份内容。每份记录包含日期、标题、正文；不关联考试、计时、批改、评分或错题统计。

正文复用现有笔记编辑器和工具栏，支持标题、列表、表格、代码块等格式。题目与答案由用户自由组织。点击「新增晨考」或在此页面按 Ctrl+N 创建；点击「保存」或 Ctrl+S 保存；Ctrl+P 切换编辑与阅读预览。自动保存延迟沿用偏好设置。

桌面版写入独立 SQLite 表 `morning_notes`，追加数据库迁移 v5→v6；浏览器开发模式使用独立本地存储。修改与切换记录期间会刷写，保存失败不允许直接切换记录，未保存草稿保留在本机供恢复。版本冲突拒绝覆盖已保存的新内容。

2026-10-09 验证：219 项单元测试通过；67 项浏览器流程通过、1 项原有条件跳过；TypeScript、Electron 与 Vite 构建通过。真实 Electron 使用独立测试数据目录验证了新增、编辑、SQLite 保存、版本冲突和重启恢复。原有浏览器 Shiki WASM/CSP 告警继续使用纯文本回退。

前一轮 AI 报错的兼容修复也已完成：已知 DeepSeek V4 Flash/Pro 名称及常用别名采用关闭思考模式的请求参数；识别输出截断、只返回思考内容与内容过滤，去掉 Electron IPC 的技术错误前缀。依据：[DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。这是根据模型名称、空响应症状和接口说明作出的兼容修复；未获取用户真实服务响应。单元测试与本机兼容接口覆盖续写及导图生成，不调用外部付费服务、不自动重试或提高输出预算。

晨考模块及 AI 兼容修复随 0.5.1 小版本更新发布。
