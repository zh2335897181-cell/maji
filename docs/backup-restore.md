# 本地备份与恢复

桌面版打开「偏好设置 → 数据与备份」。浏览器版不提供 SQLite 备份功能。

## 导出与自动备份

「导出备份」会先保存当前编辑内容，再让你选择 JSON 文件保存位置。取消文件对话框不会产生文件。

自动备份默认开启，在启动时执行：按本机日期每天最多一份；学习内容未改变时跳过。打开备份目录可查看文件。自动文件保存在 Electron 的 `userData/backups` 中（Windows 通常为 `%APPDATA%/maji/backups`，以应用显示的目录为准），最近 7 份自动备份与最近 7 份恢复前安全备份分别保留。手动导出的文件不参与自动清理。

备份包含课程、笔记及嵌入正文的图片、代码片段、练习、复习安排和答题记录、思维导图及视图、晨考。外部图片仅保留链接，不下载图片。不含 API 密钥、设备设置、缓存和日志。备份中包含学习内容，分享文件前应留意个人信息。

## 整体恢复

1. 点击「从文件恢复」，选择备份文件。
2. 查看备份时间、来源版本和内容数量。
3. 点击「确认整体恢复」。当前学习数据会整体替换，设备设置和 API 密钥保留。

恢复前会先将当前内容写成安全备份。安全备份写入失败时拒绝恢复；数据库导入失败时事务回滚，当前数据保留。成功后重新加载应用，清理旧学习草稿，空备份不会再次导入示例数据。

预览确认有效期为 5 分钟，且仅可使用一次。预览后修改学习内容需要重新选择文件并确认。应用使用预览时已验证的内容，随后替换来源文件不会改变已经确认的内容。正在执行的复习操作、未保存的导图预览或保存失败会阻止操作，完成保存后重试。

## 格式与限制

首版格式 `maji-backup`，格式版本 1，仅接受数据库结构版本 6。来源应用版本会显示在预览中，不代表可以转换其他数据库版本。文件上限 100 MiB；校验和使用 SHA-256 检查损坏，不提供加密或来源认证。不支持合并恢复。

本机自动备份适合防误删，不能防止同一硬盘损坏。建议定期手动导出到另一块硬盘或个人备份位置。应用不会自动上传文件。

## 开发验证

执行 `npm test`、`npm run build`。Windows 桌面验证执行 `node scripts/native-backup-check.cjs`，使用独立临时用户目录，不操作真实学习数据，验证 SQLite 全量往返、安全备份、重新启动和空数据恢复。
