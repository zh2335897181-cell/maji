# 桌面助手 2D/3D 导入设计

用户要求自定义导入免费、允许商用和二次开发的 2D、3D 模型，明确条例、边界与步骤。沿用现有 VRM 窗口、聊天和隔离资源协议，添加受控导入向导。

## 方案与范围

采用本地四步向导而非一键导入：选类型文件 → 技术检查与隔离预览 → 授权声明 → 确认保存/可选启用。2D 支持 PNG/GIF/WebP 图片及声明式 maji2d.json 分层角色；3D 支持内嵌资源 VRM 与 GLB。普通图片不是骨骼模型；通用 GLB 不自动具备 VRM 眼动和表情；Live2D/Spine/FBX/OBJ/ZIP/脚本包不在本次范围。作者许可不等于某运行库许可，不能用模型导入绕过运行库授权。

## 授权边界

允许 CC0-1.0、CC-BY-4.0、CC-BY-SA-4.0 或明确覆盖免费获取、商用、改编、再分发的自定义授权。要求填写作者、来源、许可原文/授权依据、署名和改动说明，并逐项确认权限；BY-SA 额外确认共享条件。非商业 NC、禁止分享改编 ND、禁止再分发、仅个人使用或授权不明不接受。

程序只检查字段完整性和内嵌许可冲突，不认证作者身份、不联网认证、不生成法律授权。授权声明不覆盖肖像、商标及第三方素材权利。不得把导入功能视作授权申请、模型编辑器或自动转换器。导入副本不自动分享、不自动打包发布、不发送给 AI。模型许可与应用/渲染库分别适用。

## 生命周期

主进程读取和校验文件，持有最多一个内存快照（最多128MB）。渲染进程只接收随机令牌，不接收任意文件访问权；预览使用独立无桥接 iframe。取消清除快照，不修改当前角色。确认后写入副本、规范化许可记录、SHA256 与时间。启用可选，默认仅加入模型库。导入失败保持当前配置。

旧自定义角色缺少授权记录时保留副本，标记待补授权，禁止选用并回退内置角色；允许补充记录。内置机器人保持可用。

## 技术边界

总计128MB，自定义最多20个；图片最多8192×8192，分层包最多32层/32表情/128图片，画布上限4096。分层包只允许目录内像素图片，不允许目录越界、符号链接、URL或脚本。GLB/VRM 仅内嵌资源，拒绝外部 URL，限制结构复杂度；若有明确内嵌商用、改编、再分发禁令，则无法通过用户勾选覆盖。

向导展示加载结果；预览失败不能确认，错误可返回重选。保留授权与能力说明查看入口，删除只移除本地副本。测试覆盖声明绕过、元数据冲突、取消不变更、失败不变更、2D/分层/GLB/VRM实际渲染与生命周期。
