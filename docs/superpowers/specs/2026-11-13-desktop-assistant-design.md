# Live2D 桌面助手

用户已选择并确认 Live2D 方案：在设置里启用桌面助手，导入角色、拖动缩放、鼠标跟随、表情动作和点击聊天，自定义昵称和性格，复用现有 AI 配置。

## Approaches

图片/GIF 方案更轻，但缺少模型交互；Live2D 方案提供角色动作，已由用户选择。采用 Electron 独立透明窗口与隔离的角色 iframe，复用 React 设置界面和主进程 AIClient。主应用不加载 Pixi。

## 实现约束

- 默认关闭，启用状态随应用重启恢复；关闭主窗口时退出助手，关闭助手按钮只隐藏，可从设置重新显示。
- 昵称、性格、大小、置顶、鼠标跟随、模型列表和位置保存在 userData/assistant；对话仅保留当前运行期间，提供清空和取消。
- 用户从官方取得 Cubism Core 后本地导入；不下载和再分发专有运行库或第三方角色。模型选择 .model3.json，复制其引用的数据文件到应用目录，检查缺失、越界、符号链接和类型；不执行角色目录内脚本。
- Core 和模型只在独立自定义协议来源的 iframe 中加载，没有 preload、Node 或 AI/笔记权限；CSP 禁止外网。主窗口与角色只交换鼠标、动作及状态消息。
- 支持 Cubism 3/4 的 model3 模型；Cubism 5 导出需实际兼容性验证，错误显示到界面。Pixi 6 与 pixi-live2d-display 0.4 固定版本配套使用。
- 聊天由主进程使用保存的 API 凭证发出，最多保留 20 条、总计 20000 字的上下文，单条用户输入 4000 字；不自动读取笔记、项目或桌面。
- 无模型、无运行库、WebGL 不可用时显示可操作的状态；导入失败保留原配置。显示器变化时将位置限制到可见工作区。

## 验证

单元测试覆盖设置校验、模型引用越界与缺失、复制失败不切换、对话验证与取消。界面流程覆盖设置、启用、导入、模型切换与聊天错误。真实 Live2D 渲染需用户自备授权 Core 与模型验证；测试替身不能证明真实模型兼容。
