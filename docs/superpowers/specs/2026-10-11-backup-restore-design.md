# 码迹本地备份与恢复设计

## 目标和范围

用户已经在码迹积累真实学习资料，需要能在误操作、更新或换电脑时找回数据。提供手动导出、恢复预览、恢复前安全备份，以及每天首次启动的自动备份；自动备份无内容变化时跳过，保留最近 7 份。首版面向 Electron 桌面端，浏览器预览显示桌面端说明，不静默导入另一套存储。

这是新增数据管理子系统。用户已同意上述功能与整体恢复方式，本文件明确其执行和失败处理边界。

## 存储方案

选择结构化 JSON 备份：显式列出学习数据表，文件带格式版本、数据库结构版本、应用版本、创建时间、内容摘要和 SHA-256 校验值。与直接复制 SQLite 文件相比，它能排除设备设置并提供准确预览；与完整用户目录打包相比，它不会误带 API 密钥、日志和缓存。校验值用于检测损坏，不是文件可信来源证明。

覆盖 courses、notes、snippets、exercises、review_items、review_sessions、review_questions、mind_maps、mind_map_views、morning_notes。保留标识、关联、时间、答案与评阅、复习计时和导图位置。标签从笔记派生，无独立标签表。排除 settings 表、ai-settings.json、API 密钥、日志与浏览器缓存。

笔记中内嵌图片随正文保留；远程图片地址只保留地址，不下载远程图片，界面说明离线可用性限制。首版不备份其他任意外部路径文件。

## 入口与交互

设置新增「数据与备份」，提供「导出备份」「从文件恢复」、自动备份开关、最近成功时间、备份目录及自动备份列表。导出使用系统保存对话框；取消不显示失败。自动备份默认开启，失败显示可重试提示但不阻止应用启动。

选择恢复文件后先验证，显示创建日期、来源版本和各类记录数量，并明确告知：整体替换当前学习数据、不合并；AI 密钥和设备偏好保持原样。用户确认后才执行恢复。恢复成功重新加载应用内容；失败显示中文原因。

## 一致性与恢复安全

备份前请求渲染进程完成笔记、晨考、导图和复习记录的待保存操作；任一保存失败则停止手动备份或恢复，保留编辑内容。启动自动备份在数据库迁移成功后、渲染界面开放编辑前进行，避免捕获未保存编辑。

导出在同一 SQLite 读取事务中获取所有表快照。自动备份使用学习数据的规范化摘要判断变化，排除 last_opened_at 等纯浏览行为及视图位置变化的判定噪声，仍在实际备份中保留这些字段。日界线使用本机日期；只在成功写入文件后记录该日已备份。

恢复准备期间禁用写操作，并等待已开始的保存完成。主进程持有已校验快照及短期一次性令牌；确认请求使用令牌，不能用任意路径或渲染进程提交的原始数据直接恢复。每次确认重新核对当前数据是否变化，变化则重新预览。

替换前强制写入当前数据库的安全备份；文件写入失败则停止。备份写入临时文件并刷新后原子重命名，防止留下看似完整的半文件。恢复使用一个 SQLite 写事务，按外键依赖顺序清空和导入表，检查外键与数据一致性；任意异常回滚。恢复和备份串行执行。

恢复完成后清理旧的恢复草稿、复习预设等与被替换学习数据有关的 localStorage 项，避免旧草稿覆盖恢复内容；保留与隐私授权、设备偏好相关的存储项。刷新界面后显示恢复成功，不重新触发旧页面的卸载保存。

## 验证与兼容性

文件先检查大小（首版上限 100 MiB）、UTF-8 JSON、格式版本、校验值、允许的表与字段。逐项验证字段类型、枚举、日期、记录 ID 唯一性、引用完整性，以及笔记文档、导图和复习结构。对用户文件不执行 SQL、脚本或文件路径操作。

首版只恢复相同备份格式及当前数据库结构版本；较新或较旧结构不猜测转换，明确说明需要兼容版本。损坏、缺表、重复 ID 或无效引用都不修改当前数据。用户看到的是验证成功后的记录数量，不是未验证的文件元数据。

## 保留规则

备份目录默认在应用 userData 下的 backups，界面提供打开目录及手动导出到其他磁盘的操作，说明默认目录与原数据同盘。自动备份保留最近 7 份；新文件写入并验证成功后才淘汰最旧文件。恢复前安全备份单独保留最近 7 份，不计入自动备份配额。用户选择位置的手动导出不参与清理。只删除受管理目录内、由本模块生成并验证过的文件。

## 验收

- 导出后恢复，全部学习模块的数据、关联、正文及图片内嵌内容一致。
- 备份不包含密钥和设备设置；恢复不覆盖现有 AI 配置。
- 损坏、超限、错误版本与关联缺失文件均拒绝且当前数据不变。
- 安全备份写入失败、事务中途失败、保存失败均不能导致数据丢失。
- 自动备份每日最多一份有效新快照，无内容变化时跳过，正确保留 7 份。
- 用户取消对话框、重复点击、恢复期间并发保存不会产生部分恢复。
- 恢复后旧草稿不会反向写入，页面显示的新数据与数据库一致。

## 非目标

云同步、账号、增量合并、多设备冲突、备份加密和定时后台服务不纳入首版。版本更新与发布待实现验收后另行执行。
