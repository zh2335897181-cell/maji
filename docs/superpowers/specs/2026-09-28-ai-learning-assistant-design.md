# 码迹 AI 学习助手设计

状态：待用户审阅；审阅通过后再写实施计划

日期：2026-09-28

## 目标

为码迹桌面版增加一个贴近笔记选区的 AI 学习面板，帮助编程初学者解释代码、整理概念和练习理解。AI 输出先预览；未经用户操作，不修改笔记、练习或复习数据。

## 已确认的产品决策

- 使用场景：用户正在阅读或编辑编程学习笔记，选中一段文字或代码后调用 AI。
- 界面方向：采用已选中的第三张设计稿——选区旁的浮动操作栏与锚定预览面板；现有右侧大纲、标签、复习和练习栏保持原样。设计参考为 `C:/Users/admin/.codex/generated_images/01a0e5ca-9e2f-7472-896b-5c4284e46a41/exec-469a8899-f267-4982-a370-be5773a44d10.png`。
- 模型接口：首版支持 OpenAI Chat Completions 兼容接口，可配置 DeepSeek 或其他兼容服务的 API 地址、模型名和密钥。
- 密钥由用户在桌面应用设置里输入；不得写进源码、SQLite 明文、日志、仓库或发布资产。
- 远端请求默认只包含选中的文本。只有用户明确切换上下文范围后才发送整篇笔记。
- 浏览器示例模式没有安全的主进程密钥存储和网络代理；AI 操作显示桌面版提示，不从 renderer 直接请求外部服务。

## 主要交互

### 选区操作

在编辑模式选中非空的正文或代码文本后，选区附近显示轻量 AI 操作栏，包含“解释这段内容”“整理成笔记”“生成练习题”。操作栏定位避开窗口边缘和选区；面板不会遮住关键代码，用户可通过 Esc 或关闭按钮收起。编辑和预览模式之外不出现选区操作。

选区操作栏显示当前上下文，例如“仅所选内容”。上下文可改为“结合整篇笔记”；当用户切换到整篇笔记时，显示明确的上传提示。关闭面板、切换笔记或选区失效时，清除已选择的上下文引用。

### AI 结果面板

点击一个操作后，锚定面板显示操作标题、上下文范围、加载状态和结果。首版不用流式输出；请求期间禁用重复提交，并提供关闭操作。失败时保留原选区与面板，显示简短原因及“重试”。面板显示结果后提供“插入到笔记”“复制回答”“重新生成”。插入操作在选区后追加结果，不替换或删除用户原文；结果作为普通文本段落插入，保留换行，不解析或执行模型生成的 HTML。

- **解释这段内容**：用简体中文说明代码或概念的作用、逐步执行过程和关键术语；只对确实适用的内容给出一个小例子。
- **整理成笔记**：将选区改写成简明标题/要点，保留原有事实与代码语义，不添加无依据结论。
- **生成练习题**：生成一题与选区对应的初学者练习，包含题目、思路提示和参考答案。面板提供“添加为关联练习”操作，明确用户确认后才写入当前笔记关联的练习列表；不自动加入复习计划。

没有选区时不发起请求，面板提示“先选中一段文字或代码”。输入上限为 12,000 个 JavaScript UTF-16 code units，输出上限为 16,000 个 UTF-16 code units，HTTP 响应体上限为 1 MiB，请求超时为 45 秒。超过输入上限时提示缩小选区，不静默截断。生成中的操作不能产生写入。

### 模型设置

偏好设置增加“AI 服务”区，可编辑兼容接口地址、模型名称、API 密钥，测试连接、保存和清除密钥。设置页显示未配置、已配置、验证失败等状态；密钥字段默认遮蔽。首次调用前告知用户选区会发送给其配置的 AI 服务，并链接回当前服务设置。

API 密钥用 Electron `safeStorage` 加密，密文存储在应用 userData 私有配置文件中；供应商地址、模型名等非密钥设置也只保存在本机。若系统密钥保护不可用或加密失败，不回退为明文存储，并给出可操作的说明。更换密钥时覆盖旧密文，清除时删除密文。

## 架构与边界

- renderer 仅接触类型化的 `window.maji.ai` 白名单接口：读取配置状态、保存服务设置、测试连接、执行选区操作。
- preload 只转发经 IPC 类型约束的 payload；不得暴露 Node、文件系统、任意 URL 请求能力或原始 `ipcRenderer`。
- 主进程负责配置校验、密钥加解密、HTTP 请求、超时、响应解析和安全错误转换。密钥不能返回给 renderer；测试连接也只返回成功/简洁错误。
- 服务仅允许 HTTPS 远端地址；如支持本地兼容服务，只允许 loopback 主机上的 HTTP。拒绝 `file:`、带用户名密码的 URL、fragment、非 HTTP(S) scheme 和任意 renderer 指定的 URL。
- 请求使用主进程的 HTTPS fetch，设置明确超时和响应大小限制；不自动重试可能产生额外费用的生成请求。非 2xx 响应、超时、离线、速率限制、无效响应格式都转换成不含密钥、完整请求体或供应商原始 URL 的简短中文错误。
- 不保存对话历史、提示词或模型响应日志；网络请求只在用户点击操作时发起。输入和输出使用有界长度，并按普通文本渲染，模型输出按不可信内容处理。
- API 密钥由用户提供；不把密钥注入开发服务器或打包元数据，不在测试快照或错误信息中记录。
- 兼容接口 base URL 只接受 HTTPS 远端地址或 loopback 主机（`localhost`、`127.0.0.1`、`[::1]`）上的 HTTP；应用在主进程拼接固定 `/chat/completions` 路径，不接受 renderer 请求目标。禁止 URL userinfo 与 fragment。
- 输入/输出按 JavaScript UTF-16 code units 分别限制为 12,000 / 16,000，HTTP 响应体不超过 1 MiB，单次请求最多 45 秒；超限不截断、不自动重试。
- 连接测试只请求配置接口的 `/models` 元数据端点，不发送笔记内容；若服务不支持该端点，设置页解释此限制，不以生成请求代替测试以免意外计费。
- 练习操作要求结构化响应：`{title, prompt, hint, solution}`，字段经长度/非空校验后才能显示“添加为关联练习”。最终映射到现有 `ExerciseInput`，使用当前笔记的 `noteId`、课程 `courseId` 和 `language`，难度默认为 `easy`。无效结构只允许重试，不得写入。

## 范围

本期包括：AI provider 设置、密钥安全存储、连接测试、IPC 服务、选区操作浮层、三种学习动作、复制/插入、练习确认写入、错误与未配置状态、窄窗口浮层定位和浏览器模式不可用提示。

本期不包括：模型账号注册或代用户购买额度、内置共享 API 密钥、云端同步、聊天历史、语音/图片输入、自动改写全文、自动保存 AI 答案、自动安排复习和流式响应。

## 验收标准

1. 用户可设置兼容接口、模型和密钥，验证连接；密钥加密保存且在 renderer 查询中不可读回。
2. AI 请求仅由用户操作触发，默认 payload 仅包含所选文本；整篇笔记只有显式更改上下文范围后才发送。
3. 编辑器支持对正文/代码选择解释、整理和生成练习；面板可关闭、重试和复制，定位不会越出视口。
4. AI 结果只有在用户点击后才追加到笔记或创建关联练习；现有正文不能被隐式覆盖。
5. 未配置、浏览器预览、离线、超时、HTTP 错误、限额和格式错误均有清晰状态；不会显示 API key 或敏感请求细节。
6. AI 服务不记录内容，也不执行模型返回的 HTML 或代码。
7. 密钥加密不可用时，保存失败且不会明文落盘。
8. 单元、组件和浏览器 E2E 测试覆盖服务验证、范围控制、无选区、写入确认、密钥隐藏、响应错误和视口边界；`npm run typecheck`、`npm test`、`npm run test:e2e` 和生产构建通过。
