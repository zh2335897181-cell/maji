# VRM 默认角色

用户希望不使用 VRoid Studio，不制作人物。已接受从现成角色中选择，人物、动物、机器人都可以。替换此前尚未发布的 Live2D 接入，保留聊天、窗口、昵称、性格与拖动缩放设置。

选择随包提供 CC0 角色 Cosmic Bot，运行时不联网、不需要外部 Core。渲染采用 MIT 许可的 Three.js / three-vrm。现有隔离来源 iframe 和最小 IPC 保持。默认启用状态仍为关闭；用户在设置启用后直接显示角色。

自定义导入改为内嵌资源的 VRM 0.x / 1.0；检查 GLB 头、长度、VRM 扩展和外部 URL。文件最多 128MB，自定义角色最多20个，内置形象不能删除。旧未发布 Live2D 设置忽略并回退默认角色，原副本不自动删除。

程序驱动待机呼吸、眨眼、目光跟随、挥手、点头和回复后的微笑；具体表情效果取决于模型。通过原生 Electron 验证实际角色渲染、布局、动作、聊天隔离和关闭重建，浏览器验证设置与错误恢复。
