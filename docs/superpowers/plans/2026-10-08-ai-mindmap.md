# AI 思维导图 Implementation Plan

Goal: 实现设计文档约定的导图生成、编辑、持久化、导出与复习衔接。
Architecture: 共享模型与严格校验；主进程读取来源、请求 AI、存储 SQLite；React 页面使用 SVG 画布与独立树布局。复用 AI 客户端及凭据。
Tech Stack: React / TypeScript / Electron / SQLite / SVG。
Spec: ../specs/2026-10-08-ai-mindmap-design.md

约束：应用版本维持 0.4.0；不发布；保留 release-scroll；新迁移只追加。

- [x] 共享模型：先测试循环、引用、导入 ID、移动、删除、布局及 Markdown，再实现。
- [x] 桌面契约：追加迁移与版本锁仓储，增加受限 IPC / preload；覆盖保存冲突与来源读取。
- [x] AI：结构化提示词、验证、取消及来源确认；覆盖不可信输出。
- [x] 页面：选择/确认/预览、列表、详情、画布操作、撤销、保存与离开保护、导出导入。
- [x] 集成：笔记入口、导航、复习预填、深浅主题及小窗口。
- [x] 验证：完整单元测试、构建及浏览器流程；记录尚无法实测的外部模型限制。

## 验证结果

- `npm run test`：33 个测试文件，198 项通过。
- `npm run build`：TypeScript、Electron 编译、Vite 构建通过。
- `npm run test:e2e`：63 项通过，1 项沿用原有视口条件跳过；包含 8 项新导图流程。
- 独立 SQLite 数据目录：新增、修改、版本冲突、视口保存、来源删除、重启恢复、级联删除和 v4→v5 迁移通过。
- 真实 Electron 窗口：preload、安全凭据、来源确认后请求、本机模拟接口生成、保存、编辑、关闭重开恢复通过。
- 外部付费模型未调用；浏览器端生成明确要求使用桌面应用。
- 原有 Shiki WASM 在浏览器 CSP 下有告警，现有纯文本回退仍可阅读代码；本轮未放宽 CSP。

实现差异及后续扩展见设计文档第 12 节。本轮未提交、推送或发布。
